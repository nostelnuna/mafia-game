# 30~35인 대규모 마피아 실시간 스마트 도우미 (현장 스마트폰 연동형)

참가자들이 현장에서 각자의 스마트폰 카메라로 QR 코드를 찍고 입장하여, **자신의 직업 확인, 실시간 투표, 밤 행동 제출**을 진행하는 시스템입니다.

---

## 🚀 방법 1. [가장 추천] Glitch를 이용해 1분 만에 무료 배포하기 (무설치, 완전 무료)

개발 지식이 전혀 없어도 누구나 바로 인터넷 주소(URL)와 QR 코드를 만들 수 있습니다.

1. **[Glitch.com](https://glitch.com/)** 에 접속하여 무료 회원가입을 합니다.
2. 우측 상단의 **[New Project]** 버튼을 누른 후 **[glitch-hello-node]** 를 클릭합니다.
3. 왼쪽 파일 목록에 있는 기본 파일들을 지우고, 이 압축 파일에 있는 다음 파일들의 내용을 그대로 복사-붙여넣기 합니다:
   * `package.json`
   * `server.js`
   * `public/host.html`
   * `public/index.html`
4. 화면 하단 **[Share]** -> **[Live Site]** 를 누르면 전 세계 어디서든 접속 가능한 **나만의 주소(예: `https://my-mafia-35.glitch.me`)** 가 생성됩니다!
5. **현장 진행 시**:
   * **노트북(빔프로젝터/TV)**: `https://내주소.glitch.me/host` 접속 (대형 QR 코드 및 현황판 표시)
   * **참가자들**: 빔프로젝터에 뜬 QR 코드를 스마트폰 카메라로 스캔하면 즉시 입장 완료!

---

## 💻 방법 2. 노트북에서 직접 실행하기 (같은 Wi-Fi 사용 시)

현장에 Wi-Fi 공유기가 있고 노트북에 Node.js가 설치되어 있는 경우:

1. 압축을 풀고 해당 폴더에서 터미널을 엽니다.
2. 패키지 설치:
   ```bash
   npm install
   ```
3. 서버 실행:
   ```bash
   npm start
   ```
4. 터미널에 표시되는 주소로 접속합니다:
   * 빔프로젝터용 화면: `http://localhost:3000/host`
   * 참가자 스마트폰 화면: `http://노트북의_내부IP:3000` (화면의 QR 코드 자동 생성)

## 🎮 게임 진행 흐름
1. **로비**: 참가자들이 스마트폰으로 QR을 찍고 닉네임을 적어 입장 (1~35번 번호표 자동 부여).
2. **시작**: 호스트가 [게임 시작]을 누르면, 인원수에 맞춰 최적의 직업(마피아/경찰/의사/탐정/시민)이 각자 스마트폰으로 비밀리에 배분됩니다.
3. **첫날 밤**: 참가자들은 스마트폰 카드를 꾹 눌러 직업을 확인 (마피아는 동료 명단 확인).
4. **낮 토론**: 타이머와 음성 안내에 따라 토론 진행.
5. **지목 투표**: 스마트폰 화면에서 의심 인물을 터치하여 실시간 투표.
6. **최후 변론 및 재판**: 스마트폰에서 [유죄] / [무죄] 즉시 투표.
7. **밤 페이즈 (40초)**:
   * 마피아: 스마트폰에서 습격 대상 투표
   * 경찰: 스마트폰으로 조사 대상 선택 -> 마피아 여부 즉시 확인
   * 의사: 치료 대상 선택
   * 시민: 평온하게 취침 화면 유지
8. **아침 발표**: 빔프로젝터 화면에서 사망자 발표 및 다음 날 진행.
